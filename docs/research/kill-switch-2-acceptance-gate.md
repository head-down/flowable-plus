## 0. 判定口径

- kill switch 2 判定的是**三条承重边界能否被主动击穿实验判定**，**不是**「验收矩阵全绿」。
- **边界是域，不变量是域内否命题。** 三条承重边界不必然只对应三条不变量——能力边界有两个承重面，展开为两条不变量。
- **不变量至上**：任何清单条目、例外、变体、豁免**都不得触及** I1–I4。不验收项清单只把「哪些情况**不构成** kill switch 2 失败」事前具名化，**不是豁免书**。
- **举证责任**：ADR 阶段交付「**可执行且非循环**的判定程序」；实测留实现期，实测结果是 ADR 的**撤销条件**，而非放行条件。kill switch 2 的举证责任不得外包给任何沙盒。

## 1. 三条承重边界 · 四条承重不变量

| id | 归属边界 | 措辞 |
|---|---|---|
| **I1** | 能力边界 · 流程状态面 | 不存在任何框架通路，使一个未经「建议提交」留痕的动作改变流程状态 |
| **I2** | 能力边界 · 数据离域面 | 不存在任何框架通路，使一份未经「出域控制」的数据离开本域 |
| **I3** | 失效边界 | 任何未产出都留下可区分的结局，绝不表现为无事的正常通过 |
| **I4** | 退出边界 | 机制未激活、或关闭 / 移除之后，不产生任何决策活动或出站调用 |

**边界分界**（互补、不重叠）：
- **退出边界**管「**未激活**、或**曾激活后被关掉 / 移除**」；
- **能力边界**管「机制**一旦激活**，其流程状态面与数据离域面仍不得被击穿」；
- **把节点的启用声明关掉**属于 I4 措辞中的「**关闭**」，**不属于**「未激活」的定义面；I4 的「关闭 / 移除」覆盖**全局关、节点级关闭、移除 extension 三层关闭**。

## 2. 最小术语钉

术语钉的目的：钉住承重名词的**适用域**，防止实现期扩大或缩小。**已有 `CONTEXT.md` 词条一律引用、不复制**（`CONTEXT.md` 是词条的唯一住所）；缺词条者补进 `CONTEXT.md`。

### 2.1 新增词条（已补进 `CONTEXT.md`）

- **出站调用**：框架经「决策目标」发出的调用；**不包括**出域策略的本地纯计算与入站加工，**也不包括不承载决策效力的日志、指标等失败观测信号**。
- **决策活动**：**本机制**产生的活动，包括建议提交、决策证据留痕、拉管线发起、装配、出站调用；**不包括** core 侧那个无订阅者的 `TaskCreatedEvent`——该事件是既有决议已登记的唯一**无感例外**，不构成机制活动；**也不包括**不承载决策效力的日志、指标等失败观测信号。
- **未激活**：全局开关关闭，或机制未装配 / 移除 extension；**显式排除**「节点未声明」（「节点未声明 ≠ 该节点零决策痕迹」，见既有决议）。
- **离开本域**：数据经「决策目标」**进入出站调用载荷，或到达外部系统**；**不要求调用成功**。只要数据进入经决策目标的**出站链路**，即视为离开本域控制面。
- **通过**（I3 的否定项）：流程状态发生改变，**或**审批轨迹上出现一条人工意见——两者任一即算「通过」，以堵住「只改流程状态才算通过」的窄化解释。

### 2.2 引用的既有词条

`建议提交`、`未产出`（**已明确为不承载契约取值的上位词，不得被读成叶子态**）、`出域控制`、`出域载荷`、`决策目标`、`决策证据组`、`采纳判定`、`表态比较面`、`运行暂停`、`启用 / 禁用` 等，以 `CONTEXT.md` 为准。

## 4. 击穿尝试的准入条件与同构变体通道

### 4.1 准入条件（不满足者，即便越了界也不构成命中）

1. 只用框架**公开且契约化**的位点（不改源码、不用反射撬私有状态）；
2. **不依赖应用侧补偿**（自建表 / 私有 JSON / 私有命名 / 额外事务包装）；
3. 可由**第三方**在无实现方内部知识下复现与判定；
4. 在**同一锚点 / 同一生命周期内**构造（不拿跨锚点、跨实例的伪场景充当越界）；
5. 越界只发生在**框架未承诺的场景**里 ⇒ 归「不验收项清单」，**不算击穿**；
6. 击穿尝试须在 ADR 阶段**具名登记**，实现期**不接受事后追加的击穿定义**。

> **实现层表达**（六条各自的强制机制与落点）：**唯一住所 = `docs/impl/0042-kill-switch-experiments.md` §3** —— 机械可判 = ① ⑥（受限源码扫描 + 规模守卫，落点 `E21`），文档纪律 = ② ③ ④ ⑤。本条只留判据文本。

### 4.2 同构变体通道（设 ④ 通道，防「新发现风险」被逼成事后移动球门或明知有问题却不能处理）

实现期新发现的风险，**四条同时满足**才算「与母实验同构」：

1. 同一承重边界；
2. 同一**越界机理**（手段类别相同，而非同一字段）；
3. 命中已登记的**同一断言面**；
4. 满足 §4.1 ①–⑤ 准入条件。

- **效力**：登记即**立即具备判定力**——变体被击穿，与母实验**同等**触发临时冻结。
- **边界**：变体通道**扩的是实验集，不是结论集**；是否构成命中、是否作废 ADR，**仍由主仓维护者裁定**。
- **任一不满足** ⇒ **不得**走变体通道，只能「另立新案」或「进不验收项清单」。
- **居所**：台账落本文件；ADR 只留判据与一条指针。

> **实现层表达**（变体行的固定格式 / 常量侧两个并列承载位 / 元守卫）：**唯一住所 = `docs/impl/0042-kill-switch-experiments.md` §4**。本条只留四条判据与效力边界。

## 5. 失败判据、分层退回与撤销

### 5.1 判据（kill switch 2 命中）

1. 某条承重**不变量写不出**满足准入的击穿实验（⇒ 该不变量描述不清晰）；
2. 某条击穿实验**达到准入条件且越界成功**；
3. 判定程序**引用未裁定结论**（循环论证——含引用仍未关闭的其他来源）。

### 5.2 分层退回（不一刀切）

- 判据①⇒ 该不变量**回炉**、**为对应来源另立新案**，机制**不砍**；ADR 的该条判定程序标为「待补」。**不进临时冻结态。**
- 判据②⇒ 机制退回「**不做**」，或按既有降级决议收缩为「**只留痕、不承载**」。
- 判据③⇒ **重写判定程序**，机制**不退回**。

### 5.3 临时冻结（开发 / 发布层面的安全操作路径）

- **定义**：发现疑似命中者**单方**将机制退回默认关 + ADR 标记「疑似命中、待裁定」+ 暂停回落主仓的 PR。
- **分层**：与运行期状态**分层**——**不是**第三个运行期状态；其运行期表现**复用既有「禁用」**。
- **权限**：**任何实现者可单方冻结，但只能冻结、不能解冻**；**解冻与最终裁定归主仓维护者**。
- **解冻**：裁定为「非同构 / 不满足准入条件 / 假阳性」⇒ 解冻，并把该次判定**登记进台账形成判例**（防同一个假阳性反复冻结）。

### 5.4 状态闭集

`草稿` → `已放行·附撤销条件` →（`疑似命中`）→ { `已放行·附撤销条件` | `作废` }

- **四态闭集**：`草稿` / `已放行·附撤销条件` / `疑似命中` / `作废`。闭集里**没有裸 `已放行`** 这一格，也不开第五格。
- **「收缩」是处置结果、不是状态**：它仅为 `作废` 的替代结局，不得成为第五个常态状态。
- **迁移与触发者**：`草稿 → 已放行·附撤销条件`（本次裁定 + 条款齐备，**维护者**）；`已放行·附撤销条件 ⇄ 疑似命中`（**任何实现者可单方进入**，只有**维护者**可退出）；`疑似命中` 之后的**处置结果**由**维护者**裁定，可包括**恢复为 `已放行·附撤销条件`**、裁定 `作废`，或**收缩为「只留痕、不承载」**。
- **撤销权归主仓维护者**，实现者不得自行宣布消解。

### 5.5 不验收项与不变量的对账形态

不验收项清单**必须逐条对账**：每条**附「不变量保持论证」**并注明归属不变量。**不接受总则式声明。**

若某条目**论证不出来**：默认走「**该条目升为承重靶子**」并按判据② 进入冻结判定；只有维护者可将不变量措辞的适用域改写（即「球门修订」），且**必须显式登记**。

### 5.6 放行与撤销条件（本次裁定，2026-09-25）

**裁定**：主仓维护者依「边界可控的验收闸门」（kill switch 2）的三条判据逐条过完，**三条均不命中**：

- **判据①（某条不变量写不出满足准入的击穿实验）**：**不命中** —— I1–I4 各有 ≥1 项具名击穿实验（见 §3 矩阵）。
- **判据②（某条击穿实验达准入且越界成功）**：**不命中** —— 按字面读成立的反例（老路径自动提交 / 应用侧自有出站调用）被**域界定**显式排除；且「域界定被证不足」这一情形已写进撤销条件（不自留后门）。
- **判据③（判定程序引用未裁定的结论）**：**不命中** —— 判定程序引用的探索期决议**均已落定**，不构成「未裁定的结论」。

⇒ 状态 **`草稿 → 已放行·附撤销条件`**。判据① / ② 的退回分支**均不触发**。

**域界定（登记）**：I1 / I2 的「框架通路」**限定在本机制**；既有的 `AutoApprovalRule` 自动提交路径（老路径）不在 I1 适用域内；应用侧自有路径的判定规则（含「但书」）见 **ADR-0042 第 13 节「适用域（域界定）」**—— **裁决面为唯一住所**，本文件不复制其文本。本域界定为**显式化**立闸时的既有域（`CONTEXT.md`「决策活动」= 本机制产生的活动；靶子① 的对抗尝试只在机制内成立），**未改写任何不变量的适用域**，**未扩台账类型闭集**（故附录 A 不新增行）。

**放行生效序**：放行**自域界定登记完成起生效**；登记完成前，I1 / I2 相关段落**不构成实现期冻结的依据**。

**撤销条件与分层回退**：见 **ADR-0042 第 13 节「撤销条件 / 分层回退」** —— 裁决面为唯一住所，本文件不重述。一句话：任一条具名击穿实验满足准入且**越界成功**（判据②）、或判定程序被证明**引用了未裁定的结论**（判据③）⇒ 维护者裁定 `疑似命中` 并按其处置；实现期发现某条不变量**写不出**实验（判据①）⇒ 该不变量**回炉 + 另立新案**，机制**不砍**、**不进冻结态**。

**用词更正（本裁定附带，2026-09-25）**：八靶子与四条不变量的关系是**满射覆盖**，不是「双射覆盖」（8 → 4，非一一对应）。涉及**覆盖关系**的两处 —— ADR-0042 第 13 节与本文件 §3 —— 已更正。ADR-0042 中**另一处「双射」**（指「出处组为空 ⇔ 直提」的守卫断言）**同名不同物，未改动**；立闸时的历史决议记录亦**不改写**。

**靶子⑥ 断言对象勘误（本次，2026-09-25）**：原 §3 第 ⑥ 行把 `AUTO_COMPLETE` 列入「表态比较面边界动作」并断言其 `NOT_COMPARABLE`。该断言**与读侧事实相冲** —— `AUTO_COMPLETE` **不是**动作层对象（主仓**无**同名 `ApprovalAction`），它只是 `CommentType` 取值，经映射后呈现为**面内**的 `action=AGREE`，故动作读取结果层无法排除它。处置三点：① 靶子⑥ **只删错误层级的对象**，`AUTO_COMPLETE` 移出断言对象清单；② 动作层确有唯一取值的边界动作（`RETURN` / `WITHDRAW` / `INVALID` / `INITIATE_COUNTERSIGN` + 操作注释组中有映射的部分）**保留** `NOT_COMPARABLE` 断言；③ `AUTO_COMPLETE` 的**不可判别性不消失**，转入 ADR-0042「不做 / 已知边界」（同族：`CONTEXT.md`「表态比较面」`_注意_`）。**不得**把本次勘误读作「机制已排除 `AUTO_COMPLETE`」—— 正确表述是「**本机制读侧契约面不能对 `AUTO_COMPLETE` 作独立动作层断言**；该不可判别性属已知边界，不属于靶子⑥ 可验收断言」。靶子集仍为八个、四条不变量未动、「不变量至上」不受影响。
