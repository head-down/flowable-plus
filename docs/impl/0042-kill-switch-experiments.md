## §0 前提更正与作废条款

### 0.1 前提更正

本方案原写「每条承重不变量（I1–I4）配**一**具名击穿实验」。按执行面 §3 的实际分布 —— I1 ← ①，I2 ← ②，I3 ← ④⑤⑥，I4 ← ③⑦⑧ —— 「每不变量恰一条」**为假**。**更正为**：

> **八项靶子各一具名击穿实验，与四条不变量为满射覆盖**（每项靶子 ≥1 条不变量、每条不变量 ≥1 项靶子；不是一一对应）。

依据：执行面 §3「**八项不合并，一实验一断言**」＋ kill switch 2 闸门裁定决议的「**双射覆盖 → 满射覆盖**」用词更正。本更正**不改写探索期决议的历史评论**。

**ADR-0042 第 13 节相应句不动** —— 该节「任一条承重不变量（I1–I4）的**具名击穿实验**」是**归属表述**（任一不变量名下的实验），**不是计数表述**，且该节正文已写「满射覆盖」。

### 0.2 作废条款：本方案不新立任何实验编号面

> **本方案不新立任何实验编号面。** 短 id 形态（如 `KS2-EXP-nn`、`K2-x` 一类，或任何与探索工作区台账 id `K2-001` 同族的编号）**一律不采用**；起草过程中出现过的「执行面 §3 增一列**实验 id**」这一措辞**即此作废**。

**勘误（防误记）**：`KS2-EXP-01 … 08` 这一具体形态**未出现于本方案的起草过程**；本方案起草中确实出现过的可作废形态是 ① Q1 原措辞「执行面 §3 增一列**实验 id**」、② Q11 备选 (b) 的 `K2-x1…x8`。**作废条款覆盖一切短 id 形态，不依赖「是否曾出现」** —— 故勘误只澄清出处、不缩小作废范围。

**具名击穿实验的身份一律写作：**

> **靶子名 + 主落点（类名#方法名）**

理由三条：① 「ADR 阶段具名登记」（准入条件 ⑥）的**具名**本已由靶子名（无证据推进 / 越域出站 / 影子活动 / 故障注入 / 重放 / 覆盖 / 三层关闭 / 校验例外）满足；② 与探索工作区「**引用一律用名称，不用编号**」的既有纪律一致；③ 避免两套序号指同一物后各自漂移。代价是与台账 id 命名族相近但**不同物**，故本条款显式钉开：**台账 id 只标识台账行，本文件不使用任何实验编号**。

## §1 全局形态

- **八项击穿实验分散住进 `docs/impl/0042-verification-landings.md` 已具名的落点类**，以**方法名**承载具体断言，本文件与执行面 §3 集中列名。**不新建集中式独立测试类** —— 新建会撞该文件 §1.2「一个被测类型一个测试类」，且集中式实验类要对框架内部动手，撞准入条件 ①。
- **主落点承裁定（唯一）、同面格只登记（可多个）** —— 撤销条件的触发面以**主落点**为准（ADR-0042 第 13 节「撤销条件」第 1 条）；同面格**不承裁定**。
- **击穿实验与「正面断言矩阵」的分界**（保住 ADR-0042 第 13 节「正面断言矩阵为回归配套，不参与本闸门裁定」不变）：由 §2 的登记表**逐行显式划分** —— 落点上「**越界成功即真命中**」的断言即击穿实验；其余机制侧正确行为断言属回归配套。判定依据 = **该断言的对象是「对抗尝试被挡下」还是「机制侧正确行为」**。同一类 / 方法可两用。

### 2.2 三处判断依据

1. **行 ⑤ 的主落点取 E12（真引擎侧）而非 C7（core 侧）** —— 执行面 §3 给该靶子的落点是 **extension 单测**，而 C7 是 core 落点；`resolveReplayOf` 的**判定语义**（C7）与**判定输入的构造**（E12：锚点内 `TIME_` 升序重排、同毫秒按数值 `ID_` tie-break）分属两侧，而**越界的可判定形态是「标注错」**，故裁定面取真引擎侧。
2. **行 ⑦ 的主落点取 E20 而非 S5 断言 1** —— E20 是「全局关 ⇄ 参照装配」对拍的正面承载；S5 断言 1 只补**面④ 事务语义**（E20 因 standalone 无 Spring 事务代理交付不了这一格，见探索期决议）。同面格里已列它，不丢信息。
3. **行 ⑥ 的断言对象（kill switch 2 闸门裁定附带勘误的消费）** —— 断言对象 = **四个动作层可名状边界动作**（`RETURN` / `WITHDRAW` / `INVALID` / `INITIATE_COUNTERSIGN`）＋ 操作注释组中在动作层确有唯一取值的部分；**`AUTO_COMPLETE` 不在断言对象内**（它不由动作层承载，属**已知边界**）。本行**明写**：**不得**出现「机制已排除 `AUTO_COMPLETE`」一类断言 —— E11 的 `#autoCompleteIsNotAnApprovalAction()` 只断「它不是 `ApprovalAction` 取值」这一**结构事实**。强制机制 = **文档纪律**，不另设负向断言。

### 2.3 靶子 ③ 与 ⑦ 的分界声明（防读成重复靶子）

二者共用「**全局关**」与「**移除 extension**」两个场景，但**断言面不同、不构成重复**：

- **靶子 ③（影子活动）**断的是**存在性** —— 未激活处**零决策活动、零出站调用**；
- **靶子 ⑦（三层关闭）**断的是**等价性** —— 三层关闭下**五面可观测结局逐字段等价**于「机制不存在」。

同场景不同断言面，故两项靶子各自成立；本条声明为**防误读**而写，**不改写任何一方的措辞**。

## §3 准入条件 ①–⑥ 的实现层表达

| 准入条件（出处 = 执行面 §4.1） | 实现层表达 | 强制机制 |
|---|---|---|
| ① 只用框架**公开且契约化**的位点（不改源码、不用反射撬私有状态） | 击穿实验的构造只引用被验框架的**公开类型**；承载文件**不 import 非公开包、不出现 `setAccessible` / `getDeclaredField` 一类撬私有状态的调用** | **机械可判** —— 受限源码扫描，落点 = `E21`（§4.2） |
| ② **不依赖应用侧补偿**（自建表 / 私有 JSON / 私有命名 / 额外事务包装） | 逐实验登记「未引入任何承载一致性的应用侧构造」 | **文档纪律** —— 登记表逐行对账（否定式扫描不可操作化，不假装做到） |
| ③ 可由**第三方**在无实现方内部知识下复现与判定 | 断言只读**公开产出**（`getApprovalHistory` 逐字段 / 部署异常 / 结构化日志与独立计数）；断言名与断言消息写明「看什么、判什么」 | **文档纪律**（受 ① 的源码扫描部分覆盖） |
| ④ 在**同一锚点 / 同一生命周期**内构造（不拿跨锚点、跨实例的伪场景充当越界） | fixture 只在**单锚点**内构造（同一实例、同一锚点），无跨锚点 / 跨实例场景 | **文档纪律** —— 可机械判的只有「登记字段非空」这类自查，不构成事实核查，故**不包装成机械判据** |
| ⑤ 越界只发生在**框架未承诺**的场景里 ⇒ 归不验收项清单，**不算击穿** | 逐实验登记**所攻的承诺句**（引 ADR-0042 节条）；无承诺句不得算击穿 | **文档纪律** —— 登记表逐行对账 |
| ⑥ 击穿尝试须在 **ADR 阶段具名登记**，实现期**不接受事后追加**的击穿定义 | 母实验规模（恰八项）非空且名与执行面 §3 逐字相同；变体行的母实验名在册 | **机械可判** —— 落点 = `E21`（§4.2） |

**结论**：六条中**机械可判 = ① ⑥ 两条**，**文档纪律 = ② ③ ④ ⑤ 四条**。文档纪律项落在本文件的登记表逐行对账上，由人评审可判。

## §4 同构变体通道：登记格式与常量形态

### 4.1 变体行的固定格式

变体**挂在母实验名下**，一行一栏，四栏逐条对账（出处 = 执行面 §4.2 的四条同构判据）：

| 栏 | 内容 |
|---|---|
| 母实验 | **靶子名**（必须落在 `EXPERIMENTS` 内） |
| 同一承重边界 | 能力 / 失效 / 退出（与母实验相同） |
| 同一越界机理 | 手段类别相同（**而非同一字段**）；与母实验的手段类别并列写出 |
| 命中同一断言面 | 母实验的断言名（**不得**新增断言面） |
| 满足准入 ①–⑤ | 逐条对账；任一不满足即**不得**走本通道 |

**边界（钉死）**：变体行**不得**填新的不变量、新的断言面、新的准入条件。不满足四条判据者，只能**另立新案**或**进不验收项清单**。变体的效力 = **登记即立即具备判定力**（与母实验同等触发临时冻结）；是否构成命中、是否作废 ADR，**仍由主仓维护者裁定**。

### 4.2 常量侧：两个并列承载位 + 元守卫

**常量类型**：`DecisionBreachExperiments`（extension `src/test`，**测试专用类型**，住 `docs/impl/0042-verification-landings.md` §3.1 测试基座）。

**两个并列承载位**（**不得合并**）：

- `EXPERIMENTS` —— **母实验**，恒为**八项**（实验名 = 靶子名 / 归属不变量 / 主落点类名与断言名）；
- `VARIANTS` —— **变体**，可空列表（母实验名 / 四栏对账 / 落点）。

**为何两个并列承载位**：合并为一个集合再加标记，就是让**同一个承载位兼职表达两件事**（「是不是母实验」与「实验内容」）；两个并列则「**扩实验集、不扩结论集**」在常量层是**字面事实** —— `EXPERIMENTS` 恒八，合法变体只增 `VARIANTS`。**禁用**形态：`isVariant` 布尔标记、以「母实验名为空」兼职区分。

**元守卫落点**：`E21` = `DecisionBreachExperimentsTest`（extension，`docs/impl/0042-verification-landings.md` §3.2 新增一行；§3 的类计数由 20 → **21**）。断言形态：

| 断言名 | 断什么 | 承哪条 |
|---|---|---|
| `#experimentsAreExactlyTheEightNamedTargets()` | `EXPERIMENTS` 恰八项，且名与执行面 §3 的八项靶子名**逐字相同** | ⑥ |
| `#everyExperimentNamesItsMainLanding()` | 每项主落点非空，且该类在本模块**反射可命中** | ⑥ |
| `#mainLandingsCoverAllFourInvariantsAndStayDistinct()` | 八主落点各自唯一，归属不变量覆盖 I1–I4 | ⑥ |
| `#variantsCarryTheirMotherExperimentName()` | 变体行的母实验名**必须**落在 `EXPERIMENTS` 内 | ⑥ |
| `#experimentsCarryNoVerdictField()` | 常量字段集**恰等**已声明坐标集，**不含** `verdict` / `hit` / `status` 一类结论字段 | 「**不扩结论集**」的机械面 |
| `#breachLandingSourcesAvoidPrivateStateAccess()` | 对 `EXPERIMENTS` 列出的每个主落点类的**源文件**扫描：命中数 **== 0**（无 `setAccessible` / `getDeclaredField` 一类撬私有状态的调用、无非公开包 import），附「**访问源文件数 ≥ 8**」防空转 | ① |

**计数守卫的形态（钉死）**：`#experimentsAreExactlyTheEightNamedTargets()` 只对 **`EXPERIMENTS`** 断言「恰八」；**不得**出现「常量表总行数 == 8」一类断言 —— 后者会被一个**合法变体**打红，而变体通道的全部意义正是允许事后扩充实验集。

## §5 两处如实披露

### 5.1 靶子⑧「不存在第二例外」的判定表达，与执行面落点格的说明

- **判定表达 = 穷举对账（文档纪律）**：登记表 ⑧ 行把 **E3 的六条断言**逐条对到 ADR-0042 第 11 节第 3 条的**阻断条件**（出现本机制扩展属性 **且** 不满足校验规则）与**三条不构成部署失败的穷举**（①本机制属性下无声明；②全局开关关且声明合法；③残留声明但内容合法）。「不存在第二例外」由该对账的**完备性**承担，**不另写断言**。**（实现期落地，2026-09-27）**：六条具名断言只覆盖部分规则格，为使对账**完备**，实现期补齐了其余分支的断言 ⇒ **实际对账口径 = 6 条具名 + 9 条分支断言**，逐分支落位见 **§5.1.1**（六条具名形态一字未动）。
- **发现路径（同属文档纪律）**：日后在本机制 URI 下**新增任何阻断条件**，登记表 ⑧ 行**必须同步扩行**；未扩即视为对账失效。
- **为何不造机械判据**：可机械判的形式是「validator 的阻断条件集恰等已声明闭集」，但它要求 validator **暴露条件集**，即开一个公开校验入口、造出**第二真相来源** —— 撞 ADR-0030（禁止无消费者的公开类型）与「不新增公开校验入口」的既有纪律。**不假装做到。**
- **执行面落点格的说明**：执行面 §3 行 ⑧ 的落点格原写「starter 集成测」，而部署期阻断的机制侧落点在探索期决议已钉为 **E3（extension，真引擎部署）**。**不改该格**，只在 §3 加注：**该格由 E3 承载，S4 承其 Spring 装配侧一半（validator 不随开关消失）**。

#### 5.1.1 逐分支对账表（2026-09-27 由节点声明与部署期校验落地，如实披露）

上条的「穷举对账」在实现期必须逐分支可核，故本节把 **E3 的断言集**逐条对到阻断条件与三条穷举。**规则清单的唯一来源 = ADR-0042 第 7 节的严格校验段 + 探索期决议 §八的逐违规分支枚举**（本表不复制规则文本，只给落位）。

**阻断面（11 条规则，逐条落位）**：

| # | 分支（规则） | 来源 | E3 断言 |
|---|---|---|---|
| 1 | 本机制命名空间下的**未知属性名** | ADR §7 · 探索期决议 §二 | `#blocksOnUnknownAttributeUnderMechanismUri()` |

**三条不构成部署失败的穷举（逐条落位）**：

| 穷举 | E3 断言 | 说明 |
|---|---|---|
| ① 本机制属性下**无任何声明** | `#doesNotBlockWhenDeclarationAbsent()` | 未声明节点既不触发也不阻断 |
| ② **全局开关关闭** ∧ 声明合法 | `#doesNotBlockWhenGlobalSwitchOffButDeclarationLegal()` | **本格在 E3 层面不真置开关**（校验器**无开关入参**：开关取值既不参与装配条件、也不进入判定 ⇒ 没有可置位点），其信息量 = 「合法声明不被主闸误伤」；「开关关 ∧ 声明**非法**仍阻断」同理由**结构**保证（判定不读开关），开关的 Spring 侧一半（validator 不随开关消失）由 `S4` 承接 |
| ③ 声明**残留但内容合法** | `#doesNotBlockWhenDeclarationIsExplicitlyDisabled()` + `#doesNotBlockWhenEnabledWithoutEffectiveDataSources()` | 「残留」的典型形态 = ADR §7 四态里的两个合法态（显式禁用 / 启用但无有效数据源）；③ 没有独立于「内容合法」的额外面 |

**完备性结论**：阻断面 **11 条规则逐条落位**、扫描域具名落位、不阻断面 **3 条穷举逐条落位** ⇒ 阻断判定唯一地由「本机制命名空间下**出现**声明 ∧ 该声明**不满足规则**」两项决定，**不存在第二例外**。「零痕迹」（阻断发生在任何持久化之前）另由 `E3` 家族的部署计数断言机械承担（**不新增落点**）。

### 5.2 靶子② 策略异常项的薄点披露

- **有归属、无直证**：探索期决议的结局映射表**行 6**（策略抛异常 / 运行期不自洽 ⇒ `SUGGESTION_FAILED` / `INTERNAL_ERROR` / ERROR / 不重试 / 落）已给结局；但「**异常 ⇒ 不进入 Provider 缝 ⇒ 无出站调用**」（即「不回退原文」这一 I2 关切）**没有一条断言正面说出**。现有 E13 `#stageOrderMatchesDeclaredChain()` 是**正常路径**的次序断言，异常路径靠 `#neverRethrowsOnAnyException()` **间接覆盖**。
- **处置 = 不补断言**：② 的「无出站调用」目前是**推理链**（次序 + 不 rethrow + 行 6），**不是直证断言**。理由：该场景是**承诺过的**（ADR-0042 第 6 节明写「抛异常 = 系统故障、计错误（出域 ⇒ `INTERNAL_ERROR`）」），故不得判为「框架未承诺的场景」；但也不为本条**扩机制侧断言** —— 能不扩就不扩。
- **若日后需要直证**：按既有纪律走**同构变体通道**或**另立新案**，**不得**在实现期悄悄补。
- **同族薄点（同批披露）**：靶子⑤ 的「**同一幂等身份重复到达 ⇒ 照记、不抑制**」这半句，落点表里亦**没有一条正面断言**直说「重复到达仍然落行」；现有承载是 C7 的判定语义（`#resolveReplayOfReturnsOriginalOrNull()`）与 E8 的四列产出路径穷举（重放不在四列之内，即**无抑制分支**）。处置同上：**登记 + 披露，不预立断言**。
